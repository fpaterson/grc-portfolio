# Brute Force Incident Report

## Overview
This repository contains the incident report and supporting evidence for a brute force attack on the website `yummyrecipesforme.com`.

## Scenario Summary
A former employee executed a brute force attack to gain administrative access. The attacker modified the website's source code to inject malicious JavaScript, which prompted visitors to download a malware executable and redirected them to a fake website (`greatrecipesforme.com`).
