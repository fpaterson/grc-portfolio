# SYN Flood Incident Report

**Course 3:** "Connect and Protect: Networks and Network Security"
**Module 3:** Secure against network intrusions

Incident report for a denial of service attack on a company web server. A packet capture showed a flood of TCP SYN requests from one unfamiliar IP address, which overwhelmed the server and made the website time out.

The report identifies the attack, explains how it disrupted the website, and describes the impact on the organization.
