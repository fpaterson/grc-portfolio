# Botium Toys: Security Audit

**Portfolio Activity:** Conduct a security audit
**Course 2:** Play It Safe: Manage Security Risks
**Module 2:** Security frameworks and controls

This project is an internal security audit for Botium Toys, a fictional company. I assessed its current controls and compliance posture (PCI DSS, GDPR, SOC 1 and 2) and wrote prioritized recommendations for the IT manager.
