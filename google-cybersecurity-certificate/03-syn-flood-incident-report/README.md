# Cybersecurity Incident Report: SYN Flood DoS Attack

**Scenario:** A travel agency's web server experienced connection timeouts, preventing employees and customers from accessing the sales webpage. 

The objective of this activity was to analyze a Wireshark TCP/HTTP log to identify a network intrusion attack, understand how it caused a service interruption, and document the findings in a standard Cybersecurity Incident Report format.

## Project Overview
- **Scenario:** A travel agency's web server experienced connection timeouts. 
- **Analysis:** Packet log analysis revealed a Denial of Service (DoS) attack.
- **Outcome:** Identified the attack as a SYN flood and documented how it exhausted the server's resources and disrupted legitimate user traffic.
